# ماجوکیت · MajooKit

فروشگاه آنلاین فارسی برای کیت‌های ماژولار MDF، همراه با نمایش سه‌بعدی، «در اتاق خودت ببین» (AR روی عکس یا دوربین زنده)، سفارش از طریق واتس‌اپ و پنل مدیریت.

- **فروشگاه:** `/`
- **پنل مدیریت:** `/admin`

## ویژگی‌ها

**فروشگاه**
- طراحی مینیمال با پالت نود، راست‌به‌چپ و موبایل‌اول (نوار پایین، دکمه‌ی خرید ثابت)
- جستجو، فیلتر بر اساس فضا، ابعاد، قابلیت توسعه و سختی مونتاژ
- مدل سه‌بعدی همه‌ی کیت‌ها (three.js) با نمای انفجاری
- «در اتاق خودت ببین»: دوربین زنده، عکس از اتاق یا انتخاب از گالری؛ گرفتن عکس، ذخیره و اشتراک‌گذاری
- ثبت سفارش در دیتابیس و باز شدن پیام آماده در واتس‌اپ با کد پیگیری
- راهنمای مونتاژ (PDF و ویدیو)، سؤالات متداول، تیکت مرجع برای هر محصول

**پنل مدیریت**
- داشبورد: سفارش‌های جدید، فروش ۳۰ روز، نمودار ۱۴ روز، پرفروش‌ها، موجودی کم
- محصولات: افزودن، ویرایش، حذف، پنهان کردن؛ آپلود و مرتب‌سازی عکس‌ها؛ PDF و ویدیوی مونتاژ؛ تغییر سریع قیمت و موجودی در جدول
- سفارش‌ها: وضعیت (جدید، تأییدشده، ارسال‌شده، تحویل‌شده، لغوشده)، یادداشت داخلی، پیام مستقیم به مشتری در واتس‌اپ، خروجی CSV برای اکسل
- درخواست‌ها: درخواست راهنمای رایگان و «خبرم کن»
- تنظیمات: شماره‌ی واتس‌اپ، نوار اطلاعیه، متن هزینه‌ی ارسال، نمایش تیکت‌های مرجع، تغییر رمز

## اجرا

نیازمند **Node.js نسخه‌ی ۲۲.۵ یا بالاتر**. پروژه هیچ وابستگی خارجی ندارد (دیتابیس با `node:sqlite` داخلی Node).

```bash
git clone https://github.com/MohiDanie/majookit.git
cd majookit
ADMIN_PASSWORD='یک-رمز-قوی' npm start
```

سپس `http://localhost:3000` (فروشگاه) و `http://localhost:3000/admin` (پنل) را باز کنید.
اگر `ADMIN_PASSWORD` را تعیین نکنید، در اولین اجرا یک رمز تصادفی در کنسول چاپ می‌شود. بعداً از «تنظیمات» قابل تغییر است.

اولین کار بعد از ورود: در «تنظیمات» شماره‌ی واقعی واتس‌اپ را وارد کنید.

### متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `PORT` | `3000` | پورت سرور |
| `ADMIN_PASSWORD` | تصادفی | رمز مدیر، فقط در اولین اجرا |
| `DATA_DIR` | `./data` | محل دیتابیس و فایل‌های آپلودی (در سرور روی دیسک ماندگار) |
| `COOKIE_SECURE` | `0` | روی سایت HTTPS مقدار `1` بدهید |

### داکر

```bash
docker build -t majookit .
docker run -d -p 3000:3000 -v majookit-data:/data -e ADMIN_PASSWORD='...' -e COOKIE_SECURE=1 majookit
```

### استقرار روی لیارا / آروان / هر هاست Node

- دستور اجرا: `npm start`
- نسخه‌ی Node: ۲۲ یا بالاتر
- یک دیسک ماندگار به `DATA_DIR` وصل کنید؛ وگرنه با هر استقرار، سفارش‌ها و عکس‌ها پاک می‌شوند.
- سایت را پشت HTTPS اجرا کنید؛ دوربین زنده‌ی AR فقط روی HTTPS کار می‌کند.

## ساختار

```
src/server.js        سرور HTTP، API عمومی و مدیریت، نشست‌ها، آپلود
src/db.js            جدول‌ها و مقداردهی اولیه
src/seed.js          ۱۳ کیت نمونه و تنظیمات پیش‌فرض
public/index.html    فروشگاه
public/assets/       استایل و اسکریپت فروشگاه (موتور سه‌بعدی، AR)
public/admin/        پنل مدیریت
test/api.test.js     تست‌های API
```

## API

| روش | مسیر | توضیح |
|---|---|---|
| GET | `/api/products` | محصولات فعال |
| GET | `/api/settings` | تنظیمات عمومی |
| POST | `/api/orders` | ثبت سفارش (قیمت در سرور محاسبه می‌شود) |
| POST | `/api/leads` | درخواست راهنما / خبرم کن |
| POST | `/api/admin/login` | ورود مدیر |
| GET/POST/PUT/PATCH/DELETE | `/api/admin/products[/:id]` | مدیریت محصولات |
| GET/PUT/DELETE | `/api/admin/orders[/:id]` | مدیریت سفارش‌ها |
| GET | `/api/admin/orders.csv` | خروجی سفارش‌ها |
| GET/PUT | `/api/admin/settings` | تنظیمات |
| POST | `/api/admin/upload` | آپلود عکس، PDF یا MP4 (حداکثر ۱۰ مگابایت) |

## نکته‌ها

- محصولات نمونه و قیمت‌ها نمایشی‌اند؛ از پنل جایگزین کنید.
- لینک‌های «تیکت مرجع» فقط به صفحه‌ی محصول مشابه در سایت ایکیا اشاره می‌کنند و هیچ محتوایی از ایکیا در این مخزن نیست.
- فونت‌ها Vazirmatn از Google Fonts و three.js از cdnjs بارگذاری می‌شوند.
